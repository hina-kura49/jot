# 機能の詳細

Jot でできることを、細かい動きまで書いています。概要は [README](../README.md) にあります。

- 見た目は、アイコンに合わせた青を基調にしています。ウィンドウは透けません。
- Notion のようなブロック編集ができます。ブロックは、ハンドルをつまんでドラッグするか、`⌘⇧↑` / `⌘⇧↓` で並べ替えられます。
- `/` を打つと、スラッシュコマンドのメニューが開きます。メニューには、テキスト、見出し1〜3、リスト、番号付きリスト、チェックリスト、トグルリスト、コールアウト、引用、コードブロック、表、区切り線、画像、ページを作る（`/page`）、Mermaid の図、ブロック数式、トグル見出し1〜3があります。Notion と同じ英語の名前（`/toggle`、`/callout`、`/divider`、`/h1` など）でも絞り込めます。
- Notion と同じ Markdown のショートカットが使えます。行頭で `# ` `- ` `1. ` `[] ` を打つと見出し・リスト・番号付きリスト・チェックリストに、`" ` か `> ` で引用になり、`---` で区切り線、```` ``` ```` でコードブロックになります（`> ` は Notion ではトグルですが、Markdown では引用の記号なので、ここでは引用のままです）。
- サイドバーにページのツリーを表示します。右クリックのメニューから、開く・子ページを作る・名前を変える・削除するといった操作ができます。子ページを持つページを削除するときだけ、件数を示して確認します。
- サイドバーの下のフォルダのボタンで、空のフォルダを作れます（ディスク上も普通のフォルダで、`.md` は作りません）。名前はその場で入力します。フォルダの右クリックのメニューから、中に新規ページ・新規フォルダを作る、名前を変える（`F2`）、削除する（`⌘⌫`）ができます。名前を変えると、ほかのページからフォルダの中へのリンクも書き換わります。
- 本文の下の空白を押すと、本文の最後に入力位置が移ります。最後のブロックがリストやコードなどなら、下に空の段落を足します。
- `/page` でページを作ると、そのページへ移ります。
- 空のフォルダを保管庫に選ぶと、使い方のノート（`Jot の使い方.md`）を1枚作って開きます。すでにノートがあるフォルダには何も足しません。ふつうのページなので、消しても書き換えてもかまいません。コマンドパレットの「使い方のノートを開く」で、いつでも開き直せます（なければ作ります）。
- `->` `>=` `!=` などは、Ghostty と同じ JetBrains Mono の合字で `→` `≥` `≠` のように表示します（見た目だけで、ファイルの中身は変えません）。本文は記号の `! - < = >` だけをこのフォントで描き、ほかの文字はシステムのフォントのままです。フォントはアプリに同梱しています（`src/assets/fonts/`、SIL Open Font License）。
- `⌘⇧E`（上の帯の右のボタン、コマンドパレットの「PDF に書き出す」も同じ）で印刷ダイアログが開きます。左下の「PDF」から「PDF として保存」を選ぶと、タイトルと本文だけの PDF になります。
- `⌘⇧H`（上の帯の右の共有のボタン、コマンドパレットの「HTML に書き出す」も同じ）で、ページを HTML 1枚に書き出します。画像とフォントも中に詰め込むので、そのファイルだけを送れば、受け取った人はブラウザで開いて同じ見た目で読めます。保管庫のほかのページへのリンクは文字だけになります。
- 上の帯の検索窓を押すと、コマンドパレット（`⌘K`）が開き、ページの名前と本文を検索できます。
- サイドバーの行（ページ・フォルダ）をつかんで、別の場所へ動かせます。行の真ん中に重ねるとその中へ（ページなら子ページに）、行の上端・下端に重ねるとその行と同じ場所へ、行のない下の空白ならいちばん上の階層へ入ります。閉じた行に重ねて少し待つと開き、端に寄せるとスクロールします。`Esc` でやめます。動かすと、ほかのページからのリンクも、動かしたページの中のリンクも、同じものを指すように書き換わります。落とした瞬間に行とパンくずが新しい場所へ動き、ファイルの移動とリンクの書き換えは裏で行います（その間に打った文字は、移動が終わってから新しい場所に保存します。動かせなかったときは元に戻して知らせます）。
- ページにアイコン（絵文字）を付けられます。タイトルの上にマウスを乗せると「アイコンを追加」が出ます。付けたアイコンはタイトルの上・サイドバー・パンくずに出ます。保存先は Markdown の先頭のフロントマターの `icon:` で、ほかの行は変えません。
- 起動を軽くするため、コードの色付けの言語の一式は、起動時には読み込みません。起動して 3 秒ほどたったときか、言語つきのコードブロックを初めて描くときに読み込みます（それより前に開いたページのコードは、読み込み終えたところで色が付きます）。
- コードブロックは、上に帯のある「窓」の形で描きます（Wryte と同じ見た目。明るい画面でも暗い面に描きます）。帯には 3つの丸・言語・コピーのボタンがあります。言語の欄は書き換えられて、Enter で決まり、Esc で元に戻ります（```` ``` ```` のあとに書く言語と同じもので、Markdown にそのまま保存されます）。コピーのボタンは、コードの中身をクリップボードに写します。
- 言語を `mermaid` にしたコードブロック（```` ```mermaid ````、または `/図` `/mermaid`）は、Mermaid の図として描きます。入力位置がブロックの外にあるときは図だけを見せ、図を押すと原文が開いて書けます。書きかけで描けないときは、直前の図を薄く残して理由を出します。Mermaid は図のあるページを初めて開いたときに読み込むので、アプリの起動は遅くなりません。HTML や PDF に書き出すと、図のまま入ります。
- 画像や PDF・HTML などのファイルを `⌘V` で貼り付けるか、Finder からドラッグで落とすと、ページの子フォルダ（ページと同じ名前のフォルダ）に保存して、その場所に入れます（1つ 100MB まで）。画像は画像として、ほかのファイルはファイルの印の付いた名前のリンクとして入ります。リンクを押すと、Mac で決まっているアプリで開きます（PDF ならプレビュー、HTML ならブラウザ）。アプリやスクリプトなど、開くと動いてしまう種類のファイルは、開かずに Finder で場所を見せます。ページを移動すると、ファイルも一緒に動きます。Finder でコピーしたファイルや、ほかのアプリでコピーした画像（ページに届かないもの）は、Mac のクリップボードを直接読んで貼ります。ドラッグ中は、ファイルが入る行の下に線が出ます。
- `⌘F` でページの中を探します（`Enter` / `⌘G` で次へ、`Shift+Enter` / `⌘⇧G` で前へ、`Esc` で閉じると当たった語を選んだ状態で本文に戻ります）。ページを開いていないときは、保管庫全体の検索になります。
- サイドバーの幅は右端をドラッグして変えられます（ダブルクリックで元の幅）。上の帯のパンくずは、押すとそのページを開く（フォルダならサイドバーでそこを開いて見せる）ことができます。
- 本文やタイトルでは、macOS の「文頭を自動的に大文字にする」「スペルの自動修正」は働きません。
- `⌃⌥Space`（どのアプリを使っていても効くホットキー）で、クイックキャプチャの小さなウィンドウが画面中央に出ます。Enter で Inbox（保管庫の直下の `Inbox.md`）に書き足して閉じます。Shift+Enter で改行、Esc で閉じます。
- メインのウィンドウを閉じても（閉じるボタン・⌘W）、隠れるだけでアプリは動き続けます。ホットキーとクイックキャプチャもそのまま使えます。Dock のアイコンを押すと、もう一度出ます。終了は ⌘Q です。
- ホットキーを登録できなかったときは、メインのウィンドウの通知で知らせます。アプリはそのまま使えます。
- `⌘K`（`⌘P`、`⌘F` も同じ）でコマンドパレットが開きます。ページのタイトル・本文の検索・コマンドを、ひとつの入力欄から探せます。入力が空のときは最近開いたページを出し、`⌘1`〜`⌘5` で開けます。
