# Vim のキー操作

コマンドパレット（`⌘K`）の「Vim のキー操作を切り替える（オン・オフ）」で、本文を Vim と同じキーで書けるようにします（IdeaVim くらいの範囲）。オン・オフはこの端末に覚えます。既定はオフです。タイトル・検索欄などは、オンでもいつもどおりです。

- 右下に今のモード（`NORMAL` `INSERT` `VISUAL` `V-LINE`）と、打ちかけのキーが出ます。ページを開くと `NORMAL` から始まります。
- 日本語入力: `NORMAL` と `VISUAL` の間は本文を「編集できない状態」にするので、日本語入力（Mozc など）がオンのままでも `h` `j` `k` `l` などがそのまま効き、変換中の文字が本文に入りません。`i` などで `INSERT` に入ると、いつもの入力に戻ります。変換中の `Esc` は変換の取り消しに使われ、確定したあとの `Esc`（か `Ctrl+[`）で `NORMAL` に戻ります。
- 1文字は見た目の1文字です。絵文字や「𠮷」のような字を途中で切りません。
- 単語（`w` `b` `e` `iw`）は、ひらがな・カタカナ・漢字・英数字・記号の切れ目で区切ります（「日本語のテキスト」なら「日本語」「の」「テキスト」）。
- 行: 段落・見出し・リストの項目などのブロック1つが1行です。コードブロックの中と、段落の中の改行（Shift+Enter）は、その改行で分けます。`j` `k` は行ごと、`gj` `gk` は画面の上の折り返した行ごとに動きます。
- `NORMAL` では、打ったキーが文字として本文に入ることはありません。`⌘`（Linux では `Ctrl`）のショートカットはいつもどおり効きます。`Ctrl` を使う Vim のキーは `Ctrl+R`（やり直し）・`Ctrl+D` / `Ctrl+U`（半画面）・`Ctrl+[`（`Esc`）だけです。

使えるキー:

- 移動: `h` `j` `k` `l` `w` `W` `b` `B` `e` `E` `ge` `gE` `0` `^` `$` `g_` `gg` `G` `f` `F` `t` `T` `;` `,` `%` `{` `}` `+` `-` `Enter` `gj` `gk` `Ctrl+D` `Ctrl+U` `zz`。数（`3w` など）も付けられます。
  - `f` `t` は全角の文字にも当たります。`f.` は「。」、`f,` は「、」、`f(` は「（」、`f[` は「「『【」にも当たります（`NORMAL` では日本語を打てないため）。
- 演算子: `d` `c` `y` `>` `<` `gu` `gU` `g~`。移動・テキストオブジェクトと組み合わせられます（`dw` `c$` `y2j` など）。`dd` `cc` `yy` `>>` `<<` は行ごと。
  - `>>` `<<` はリストの項目を1段深く・浅くします。コードブロックの中では空白2つ分ずらします。
- テキストオブジェクト: `iw` `aw` `iW` `aW` `i"` `a"` `i'` `a'` `` i` `` `` a` `` `i(` `a(`（`ib`）`i[` `a[` `i{` `a{`（`iB`）`i<` `a<` `ip` `ap`。
  - `i(` は「（）」にも、`i[` は「「」『』【】〔〕」にも効きます（`ci[` で「」の中を書き換える、など）。
- そのほか: `i` `a` `I` `A` `o` `O` `gi` `x` `X` `s` `S` `D` `C` `Y` `p` `P` `r` `~` `J` `gJ` `u` `Ctrl+R` `.`（直前の変更を、打った日本語ごと繰り返す）。
  - `o` `O` は Enter と同じ動きで行を足します（リストなら次の項目、コードなら次の行）。
  - `J` は、つなぐ所が日本語なら空白を入れません。
  - `dd` `yy` で覚えた行は、太字などの書式やリストの形のまま `p` `P` で貼れます。覚えた内容はアプリの中だけのもので、ほかのアプリへのコピーは `VISUAL` で選んで `⌘C` です。
- ビジュアル: `v`（文字）`V`（行）。選んで `d` `x` `y` `c` `s` `>` `<` `~` `u` `U` `J` `r` `p` `P` `I` `A` `o`（反対の端へ）。マウスで選んでも `VISUAL` になります。
- 探す: `/`（`?`）でページの中を探す欄が開きます（日本語も打てます）。`Esc` で閉じると、当たった語の頭にカーソルが移ります。そのあと `n` `N` で次・前へ。`*` `#` はカーソルの単語を探します。

まだないもの: `:` のコマンド、レジスタ（`"a` など）、マクロ（`q`）、マーク（`m`）、矩形のビジュアル（`Ctrl+V`）、置き換えモード（`R`）。
